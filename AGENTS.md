# dsh-workspace-family

This repository is a thin aggregate bundle, not a behavior plugin.
It combines three workspace plugins into one Plugins card.

- Do not add Host or Client code here. Each row must keep pointing at its own package.
- `aggregate.yml` is the source of truth for dependencies and row order.
- `cordis.patch.yml`, `package.json` dependencies, `dsh.bundle.patch`, and
  `dsh.aggregate.plugins` are generated by the workspace `tools/dsh-aggregate` tool.
- Keep the source plugins' row ids unchanged. Existing profile overrides are keyed by row id.
- Never install this aggregate alongside the three independent bundles; duplicate row ids are fatal.
- After editing the manifest, run `pnpm run aggregate` and `pnpm run check`.
- Read [project documentation](docs/README.md) before changing install or migration behavior.
