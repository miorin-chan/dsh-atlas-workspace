# Plan modular de mejora de los espacios de trabajo

Encuentra sesiones, cambia de espacio de trabajo y previsualiza archivos.
Consulta el nombre del espacio junto al título de la sesión y elige un ajuste preestablecido
del agente para cada espacio.
Puedes activar o desactivar cada función por separado.
