# Modularer Plan zur Verbesserung der Arbeitsbereiche

Finden Sie Sitzungen, wechseln Sie den Arbeitsbereich, sehen Sie sich Dateien
in der Vorschau an und legen Sie für jeden Arbeitsbereich eine Standard-Agent-Voreinstellung fest.
Jede Funktion lässt sich separat ein- und ausschalten.
