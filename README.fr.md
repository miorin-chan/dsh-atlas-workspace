# Plan modulaire d’amélioration des espaces de travail

Retrouvez vos sessions, changez d’espace de travail et prévisualisez vos fichiers.
Retrouvez le nom de l’espace à côté du titre de la session et définissez un préréglage
d’agent par défaut pour chaque espace.
Chaque fonction peut être activée ou désactivée séparément.
