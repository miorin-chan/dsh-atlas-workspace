Находите сеансы, переключайтесь между рабочими пространствами и просматривайте файлы.
Рядом с заголовком сеанса отображается имя рабочего пространства.
Для каждого пространства можно задать предустановку агента по умолчанию.
Каждую функцию можно включать и выключать отдельно.
