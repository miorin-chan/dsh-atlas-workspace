# Modularer Plan zur Verbesserung der Arbeitsbereiche

Finden Sie Sitzungen, wechseln Sie den Arbeitsbereich und sehen Sie sich Dateien in der Vorschau an.
Neben dem Sitzungstitel steht der Name des Arbeitsbereichs.
Für jeden Arbeitsbereich lässt sich eine Standard-Agent-Voreinstellung festlegen.
Jede Funktion lässt sich separat ein- und ausschalten.
